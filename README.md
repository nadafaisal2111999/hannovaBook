# 📚 Book Reader App (تطبيق قراءة الكتب)

تطبيق متطور لقراءة وإدارة الكتب مصمم بلغة Dart باستخدام إطار عمل Flutter. يهدف التطبيق إلى توفير تجربة قراءة سلسة ومريحة للمستخدمين مع دعم الميزات المتقدمة مثل حفظ العلامات المرجعية، تظليل النصوص، الترجمة الفورية، وإمكانية التحكم الكامل بسمات القراءة والوضع الليلي.

---

## ✨ المميزات الرئيسية (Key Features)

- **📖 إدارة الكتب والفصول:** عرض الكتب بشكل منظم وتقسيم المحتوى إلى فصول لتسهيل التصفح والقراءة.
- **💾 تخزين محلي فعال (Hive):** استخدام حزمة Hive لحفظ العلامات المرجعية (Bookmarks)، النصوص المظللة، وإعدادات المستخدم بشكل سريع وآمن.
- **🌐 الترجمة الفورية:** إمكانية ترجمة النصوص المحددة مباشرة إلى اللغة العربية أثناء القراءة.
- **🎨 سمات وقوالب القراءة:** دعم الوضعين الداكن (Dark Mode) والفاتح (Light Mode) مع خيارات تحكم مرنة في مظهر القراءة.
- **⚡ أداء عالي وسلس:** مبني بأفضل ممارسات Flutter لضمان سلاسة التنقل بين الشاشات واستهلاك منخفض للموارد.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Framework:** [Flutter](https://flutter.dev/)
- **Language:** [Dart](https://dart.dev/)
- **Local Storage:** [Hive](https://docs.hivesdb.dev/) (لتخزين البيانات والعلامات محلياً)
- **State Management:** Provider / BLoC (حسب هيكلة مشروعك)
